# Guidely Pondicherry – landing page

Admission landing page for Guidely Pondicherry, live at https://guidelypondicherry.in (hosted on Netlify).

- `index.html` – the page. Settings (lead sheet URL, Tag Manager ID, phone numbers, free mock/PDF links) are in the `window.GP` block near the top.
- `guidely-logo.png` – official Guidely logo
- `robots.txt`, `sitemap.xml` – for search engines
